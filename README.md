# StarterStack

Eine statische Nutzseite, die Besuchern konkrete Tool-Stacks fuer Online-Projekte empfiehlt.

## Lokal testen

Oeffne `index.html` direkt im Browser. Kein Backend und kein Dev-Server notwendig.

## Inhalt

- Hero mit klarem Nutzen fuer Besucher
- Interaktiver Finder fuer Dienstleistung, Online-Shop, Creator-Projekt und Lernen
- Konkrete Tool-Karten mit direkten Zielseiten
- Start-Checkliste
- Tool-Bibliothek
- Erklaerung, wie Direktlinks spaeter durch Affiliate-Links ersetzt werden koennen

## Monetarisierung

Die Seite ist zuerst fuer Besucher nuetzlich. Wenn ein Tool ein Partnerprogramm hat, ersetzt du die direkte URL durch deinen persoenlichen Affiliate-Link. Affiliate-Links muessen transparent gekennzeichnet werden.

Wichtig: Provisionen sind nicht garantiert. Traffic, Vertrauen, passende Suchintention und akzeptierte Partnerprogramme entscheiden, ob daraus Einnahmen entstehen.
